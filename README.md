# MyTerm

MyTerm 是為 **Apple Silicon 與 macOS 26** 設計的原生 SSH 管理工具。它把主機管理、SSH、本機 Terminal、Serial Port 與雙欄 SFTP 放在同一個 App 中；不登入帳號也能完整使用本機功能。

目前正式版本：**1.0.17**

## 主要功能

- 多階層群組、搜尋、主機卡片與可選的預設使用者名稱；主機庫會把最近成功 SSH 連線的主機依序移到前方，尚未連線的主機維持穩定順序。在「所有主機」頁面可把主機卡片拖到內容區的分類卡片，確認後直接移動分類。
- 密碼、私鑰、SSH Agent／config 驗證，以及系統預設、舊式 RSA 相容與自訂演算法。
- 使用系統 OpenSSH 與 MyTerm 專用 `known_hosts`，新主機金鑰必須由使用者確認。
- SSH 連線中可查看繁體中文階段摘要及保留 OpenSSH 原始措辭的錯誤記錄；底層 verbose debug 只用於判斷階段，不會顯示或複製，原始錯誤也會先遮蔽本機路徑與機密資訊。失敗時會分類常見的網路、驗證、主機金鑰、私鑰與演算法問題，並提供重試、編輯主機及複製診斷記錄；已登入的連線中斷後，可在同一分頁按 Enter 原位重連並保留本機終端捲動紀錄。成功後即釋放診斷內容，異常退出留下的短期記錄則在下次啟動時清理。
- 主機庫左側的「Logs」會記錄互動式 SSH 的連線時間、持續時間、連線當下的主機與帳號端點、來源裝置，以及進行中、完成、失敗、取消或未完整結束等結果；可搜尋與篩選。Logs 不記錄輸入命令或終端機輸出，只保留最近 30 天。
- 主機密碼保存於本機 AES-GCM 加密保管庫；只有一把根金鑰存於 macOS Keychain。密碼不寫入主機資料檔，也不透過剪貼簿填入。
- 視窗最上方的單一工作區列整合主機、SFTP、SSH 分頁、本機 zsh 與 Serial Port；終端機分頁可用滑鼠重新排序，快捷鍵會跟隨畫面順序。
- 可把終端機分頁往下拖入相鄰連線的內容區，依綠色預覽合併為左右或上下雙窗格；一般分頁優先與前一個連線合併，第一個分頁則會使用後一個連線。每個 Workspace 最多兩個連線，可拖曳分隔線調整比例、個別切換焦點或關閉，也可把窗格標題列拖回頂部分頁列重新拆開。
- 終端內容區使用文字選取游標與固定不閃爍的輸入游標；一般 shell、`cat` 與持續輸出可直接拖曳、雙擊或三擊選取。Vim、tmux 等程式明確啟用 mouse reporting 時，普通點擊、拖曳與滾輪交由遠端程式處理，Shift＋拖曳仍可強制建立 MyTerm 本機文字選取。
- SFTP 上傳、下載、覆蓋確認、新增資料夾、重新命名、刪除與權限調整；本機與遠端列表會在名稱下方顯示 POSIX symbolic 權限，編輯時可使用擁有者／群組／其他人的讀寫執行矩陣或八進位數字。可從 Finder 把檔案或資料夾拖到右側遠端窗格，上傳至目前遠端目錄；本機面板可在 App 內進入 OneDrive 等符號連結資料夾。
- 主機庫與 SFTP 使用一致的滑過、單擊選取及雙擊開啟操作；深層 SFTP 路徑會自動保留關鍵層級並以 `…` 收合中段目錄。
- 統一的藍白語意配色涵蓋主視窗框架、側欄、主機卡片、Logs、SFTP、Terminal 工作區與設定，並支援跟隨系統、淺色與深色外觀；終端機 ANSI 色彩、平台 Logo 及成功／警告／錯誤狀態仍保留原有辨識語意。
- MyTerm／Termius 主機資料匯入、可選項目預覽與 MyTerm 主機資料匯出；Termius 的資料邊界與選用轉換工具見 [Termius 主機資料遷移](TERMIUS_MIGRATION.md)。
- 可調整或停用的 App 內快捷鍵；已儲存密碼只會在安全的密碼提示階段允許填入。若第一次自動登入密碼已失效，MyTerm 只會在 OpenSSH 驗證下一次手動輸入成功後詢問取代；強制改密碼則要求兩次新密碼一致且伺服器明確回報成功，才會詢問更新本機保管庫。
- 自動辨識終端機輸出中的作業系統或網路設備資訊；尚未辨識的 SSH 主機會使用唯讀背景探測，並在主機庫、SFTP、連線分頁、終端機標題與該次 Logs 紀錄使用一致的平台徽章。
- Sparkle 安全更新，可由「MyTerm → 檢查更新⋯」下載並安裝正式版本。

## 選用的跨裝置同步

同步預設關閉。需要時登入 Google 帳號、開啟同步並設定同步密語，MyTerm 才會同步主機、群組、主機密碼與已結束的 Logs 紀錄。

- 每筆資料在 Mac 上以 AES-256-GCM 端對端加密後才送往 Firebase。
- 同步密語使用 Argon2id 派生金鑰；Master Key 與解密後密碼只保存在各台 Mac 的本機加密保管庫。
- Firebase 保存密文與必要的版本資訊，無法直接讀取主機內容或密碼。
- Logs 只在連線完成、失敗、取消或恢復為未完整結束後同步一次；連線中的狀態與計時只存在發起連線的 Mac，不會持續傳送到其他裝置。
- 「立即同步」會讓目前這台 Mac 上傳並拉取資料；其他 Mac 會在自行立即同步、App 回到前景或前景定期同步時取得變更，不是由來源裝置直接推送畫面狀態。
- 私鑰檔案、私鑰路徑及 `known_hosts` 永遠只保留在各台 Mac。
- 可停用同步並繼續以純本機模式使用 App。

安裝官方發布版不需要自行建立 Firebase 專案。只有從原始碼建置並希望使用自己的 Google 登入與同步後端時，才需要依照 [Firebase 自架同步設定](FIREBASE_SETUP.md) 完成前置作業；缺少雲端設定不影響純本機功能。

## 安裝需求

- Apple Silicon Mac（arm64）
- macOS 26 或更新版本

下載並解壓縮後，請先把 `MyTerm.app` 移到「應用程式」資料夾，再從該位置啟動。不要直接從 ZIP、磁碟映像、下載後的暫時位置或唯讀位置執行；macOS App Translocation 或無法替換 App 的位置會阻止 Sparkle 完成更新。

目前版本未加入 Apple Developer Program，因此第一次從網站下載後，macOS 仍可能顯示無法驗證開發者；請在「系統設定 → 隱私權與安全性」確認檔案來源後允許開啟一次。零費用自簽憑證沒有 Apple Team ID，無法保證跨版本延續 Keychain 身分；所有本機機密已集中於單一加密保管庫，使更新後需要的 Keychain 驗證不會隨主機數量增加。App 內更新仍會另外驗證 Sparkle Ed25519 簽章。

## 基本使用

1. 按「＋」建立群組或主機；主機名稱留空時會顯示主機位址。
2. 預設使用者名稱可以留空，連線時再選擇帳號。
3. 一般主機維持「系統預設」演算法；只有確認為舊設備時才啟用 RSA 相容或自訂演算法。
4. 雙擊主機卡片建立 SSH 分頁。第一次看到主機指紋時，請先透過可信管道核對。
   連線成功後，該主機會在主機庫的所有主機、所屬群組與搜尋結果中移到最前方；連線失敗或取消不會改變順序。這項最近使用順序只保存在目前這台 Mac，不影響 SFTP 主機選擇器。
   若要整理分類，可在「所有主機」頁面將主機卡片拖到內容區的分類卡片；核對來源與目標後按「移動」。若主機原本已有分類，會以新分類取代；拖回相同分類或取消確認都不會修改資料。進入分類後可用內容區上方的「所有主機 › 分類」路徑返回任一上層。
   若已登入的 SSH 因 VPN、網路或遠端服務中斷，MyTerm 會保留原分頁與本機終端畫面；恢復連線條件後，在該終端按 Enter 即可原位重連。這只保留 MyTerm 的顯示／捲動紀錄，不會復原遠端 shell 的工作目錄、環境或程序；需要恢復遠端工作狀態時仍應使用 `tmux` 或 `screen`。
5. 已儲存的 SSH 登入密碼會在第一次登入提示自動送出；若舊密碼被拒絕，下一次手動輸入成功後可安全更新儲存值。遇到伺服器強制改密碼時，完成「目前密碼、新密碼、再次確認」且伺服器回報成功後，MyTerm 會詢問是否以新密碼取代舊值。`sudo`／`su` 等後續提示仍需按「填入密碼」或使用設定的快捷鍵。
6. 主機庫左側欄預設收合，可用視窗頂部的側欄按鈕展開；其中「Known Hosts」與「Logs」分別開啟 SSH 信任記錄與連線軌跡。Logs 可依主機、端點、來源裝置或結果搜尋與篩選；紀錄為唯讀並自動保留 30 天。啟用跨裝置同步後，只有已結束的 Logs 紀錄會以端對端加密形式同步。
7. 「Terminal」開啟位於目前使用者家目錄的本機 zsh；「Serial」連接 `/dev/cu.*` 或 `/dev/tty.*` 裝置。一般終端輸出可直接拖曳選取；若 Vim、tmux 等程式啟用了終端滑鼠模式，普通滑鼠操作會由該程式接收，需要複製畫面文字時可按住 Shift 再拖曳。
8. 「SFTP」開啟本機與遠端雙欄檔案工作區；單擊選取主機、分類或檔案，雙擊才會進入分類／資料夾或建立連線。檔名下方會顯示例如 `-rw-r--r--` 的實際權限；從檔案選單選擇「編輯權限」後，可核對完整路徑，再以視覺矩陣或 `644`／`755` 等八進位數字調整。
9. 在頂部分頁列內拖曳終端機分頁可重新排序；把分頁往下拖入內容區時，MyTerm 會顯示相鄰的合併目標，並以綠色區域預覽放手後的左、右、上或下雙窗格位置。一般分頁使用前一個連線，第一個分頁改用後一個連線。合併分頁固定顯示為「Workspace」，最多容納兩個連線；可拖曳分隔線調整比例，或把任一窗格的標題列拖回頂部分頁列重新拆開。

## 從原始碼建置

需要 macOS 26、Apple Silicon，以及 Xcode 26 或相容的 Command Line Tools。

```sh
git clone https://github.com/crazy01100/myterm.git
cd myterm
./scripts/run-tests.sh
./scripts/run-dev-app.sh \
  --version 0.0.0-dev.1 \
  --build "$(date '+%Y%m%d%H%M%S')"
```

從原始碼 checkout 建置時，測試 App 固定輸出到 `build/dev/MyTerm Dev.app`，並使用獨立的 Bundle ID、Application Support 目錄與本機保管庫 Keychain service；Google session 也按通道隔離，Dev 不會匯入正式版的舊登入，需自行登入測試帳號。腳本只會關閉與重啟這個路徑，不會讀寫或變更 `/Applications/MyTerm.app` 的正式資料。這是建置與程序隔離規則，不是 App 執行時的目錄依賴；已驗證的 Dev App 若交由另一台 Mac 人工測試，建議放在 `~/Applications/MyTerm Dev.app`，也可使用其他穩定、可寫入的本機資料夾。候選版與發布成品則分別放在帶版本與 Build 的 `build/candidates/`、`build/releases/`。`build/`、SwiftPM 快取、ZIP 與本機 Firebase／OAuth 設定都不屬於原始碼，不會提交至 Git。

各建置通道、腳本用途、候選版與發布流程請見 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 資料與安全界線

- 主機清單不包含密碼；所有本機機密共用 AES-GCM 保管庫，其單一根金鑰使用 `WhenUnlockedThisDeviceOnly` Keychain 項目。
- 主機匯出檔是明文，可能包含位址、帳號與備註，必須由使用者自行妥善保管。
- MyTerm App 不直接讀取 Termius Vault。Repository 的選用工具只轉換相容的主機／群組中繼資料，不處理密碼或私鑰；完整限制見 [Termius 主機資料遷移](TERMIUS_MIGRATION.md)。
- 主機／群組刪除會以通過端對端驗證的加密刪除標記同步；套用遠端刪除前會先建立本機還原備份。
- Logs 是敏感使用軌跡，包含主機名稱、帳號端點、來源裝置、時間與連線結果；不進入主機匯出，也不包含密碼、命令、終端機輸入／輸出或 OpenSSH verbose debug。紀錄為唯讀，最多保留 30 天與 5,000 筆；啟用同步時，已結束紀錄會以 Master Key 端對端加密後同步，雲端看不到其明文內容。
- `sudo`／`su` 密碼不會自動送出，需在已辨識的安全提示中按按鈕或快捷鍵。

更多信任邊界與儲存方式請見 [SECURITY.md](SECURITY.md) 及 [ARCHITECTURE.md](ARCHITECTURE.md)。
