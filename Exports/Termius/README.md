# Termius 主機資料匯出

匯出時間：2026-08-07

## 內容

- `termius-hosts.json`：後續匯入 MyTerm 時使用的完整結構化資料。
- `termius-hosts.csv`：方便人工檢查與試算表檢視。
- 共 41 台主機、8 個群組。
- Termius 的巢狀群組有完整保留，例如 `CDX / CDX_Prod` 與 `CDX / CDX_Dev`。

## 安全與匯入方式

- 匯出檔不含密碼、私鑰、私鑰密語、登入權杖或其他憑證內容。
- 3 台主機原本沒有預設使用者名稱。
- 2 台主機在 Termius 中使用私鑰；匯出檔只保留「曾使用私鑰」的布林標記，不包含金鑰內容。
- 找到 1 組相同的連線資訊，資料仍原樣保留，沒有自行去除。
- MyTerm 0.8 可在 **資料 > 匯入主機資料…** 或 **設定 > 匯入與匯出** 選擇 `termius-hosts.json`。
- 選擇檔案後會先顯示群組、主機、重複與無效項目的預覽；尚未確認前不會修改 MyTerm 現有資料。
- 預設選取全部主機；切換到「自訂選擇」後，可以搜尋並逐台勾選，先進行少量主機的匯入測試。

匯入會依「主機位址 + 連接埠 + 使用者名稱」產生衝突預覽，預設跳過重複連線，也可以選擇保留兩筆；不會直接覆蓋既有資料。正式寫入前，MyTerm 會先建立目前主機資料的本機備份。
