# MyTerm 雲端同步與正式發布總覽

最後更新：2026-08-10

此目錄是 MyTerm「選用的跨裝置同步」與「正式發布」工作的主要紀錄。無論雲端功能是否啟用，App 都必須能在沒有帳號、沒有網路的情況下完整使用本機功能。

## 進度狀態

| 狀態 | 意義 |
|---|---|
| `尚未開始` | 尚未進行實作。 |
| `進行中` | 已開始，但驗收證據尚未齊全。 |
| `受阻` | 需要明確的外部資料、帳號、權限或決策。 |
| `已完成` | 已完成驗收，並記錄測試、建置或人工確認結果。 |

## 建議執行順序

1. 整理儲存庫與外部帳號，確認不會公開個人資料。
2. 加入選用的 Google Desktop OAuth 與 Firebase REST 登入，但先不傳送主機資料。
3. 完成加密、復原金鑰與格式版本設計。
4. 同步加密後的群組與主機資訊。
5. 以單一開關啟用主機、群組與密碼同步。
6. 使用至少兩台 Mac 測試衝突、刪除、離線與復原情境。
7. 先用本機 ARM Mac 建置 ad-hoc 測試版並上傳 GitHub Releases；Cloudflare Pages 只放靜態網站。
8. 整合 Sparkle 簽章更新；Developer ID 與公證是未來可選升級，不阻擋第一個免費正式版。

## 進度維護規則

每次實作都必須在同一次變更中更新對應文件的任務狀態。只有在驗收證據已記錄時，才能標示為 `已完成`。驗收證據可以是測試結果、建置結果、畫面截圖、發布網址或人工驗證紀錄；不能只因程式碼已寫完就宣告完成。
