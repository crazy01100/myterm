安裝說明

第一次安裝

  1. 下載並解壓縮 MyTerm。
  2. 將 MyTerm 移到「應用程式」資料夾。
  3. 若 macOS 顯示無法驗證，前往「系統設定 → 隱私權與安全性」，確認檔案來源後選擇仍要打開。

請勿直接從 ZIP、磁碟映像、下載後的暫時位置或唯讀位置執行。這些位置可能觸發 macOS App Translocation，或讓更新器無法替換 App；放入「應用程式」後才能穩定使用 App 內更新。

現階段 MyTerm 沒有加入付費的 Apple Developer Program，因此第一次安裝可能出現 Gatekeeper 提示。後續 App 內更新仍會使用獨立簽章驗證。

後續更新

從 MyTerm 選單選擇「檢查更新…」。MyTerm 會驗證更新清單與下載檔，驗證成功後才允許安裝。
